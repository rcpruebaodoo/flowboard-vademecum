# flowboard-vademecum

Repositorio público de datos farmacológicos para Flowboard.

Incluye 5 fármacos con capa ANMAT/PAMI validada:
- Remifentanilo
- Fentanilo
- Morfina
- Tramadol
- Dexmedetomidina

CIMA/AEMPS e IQB quedan pendientes.

IMPORTANTE: no subir datos de pacientes, historias clínicas, DNI, teléfonos, credenciales, cookies ni datos del HIS.

## GitHub Pages
1. Crear repositorio público `flowboard-vademecum`.
2. Subir todo el contenido de esta carpeta a la raíz.
3. Settings → Pages.
4. Source: Deploy from a branch.
5. Branch: `main`, folder: `/(root)`.
6. Guardar y abrir la URL publicada.
